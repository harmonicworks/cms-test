# cms-test (throwaway)

A temporary copy of harmonicworks.org to try out two blog editors side by side. **Delete this repo when testing is done.**

- Site: https://harmonicworks.github.io/cms-test/
- Decap (with draft board): https://harmonicworks.github.io/cms-test/admin-decap/
- Sveltia: https://harmonicworks.github.io/cms-test/admin-sveltia/

Differences from the real site: no CNAME (doesn't claim the domain), noindex + robots.txt block, `future: false` for scheduling, a daily rebuild workflow, and the preview-image tag accepts full paths from the editors.
